# aleradev12 Homebrew tap

Install ReelConverter on Apple silicon macOS 13+:

```sh
brew install --cask aleradev12/tap/reelconverter
```

The app is not Developer ID signed or notarized. macOS Gatekeeper may block it; see the [ReelConverter README](https://github.com/aleradev12/reelconverter#install) before installing.
