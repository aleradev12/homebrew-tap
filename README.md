# aleradev12 Homebrew tap

Install ReelConverter on Apple silicon macOS 13+:

```sh
brew install --cask aleradev12/tap/reelconverter
```

The Cask installs only the app. On launch, ReelConverter checks for FFmpeg and offers to install it if needed. The app is not Developer ID signed or notarized, so macOS Gatekeeper may block it; see the [ReelConverter README](https://github.com/aleradev12/reelconverter#install).
